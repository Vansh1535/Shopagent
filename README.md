## What is ShopAgent?

ShopAgent is a full-stack agentic commerce platform built for Indian merchants and buyers. It solves three real problems:

**For Sellers** — Most Indian MSMEs publish products with messy, unstructured descriptions. ShopAgent's AI Catalog Normalizer transforms raw listings into clean, agent-readable structured data — with zero hallucination. Prices and stock are always sourced from the seller's live database, never generated by AI.

**For Buyers** — ShopAgent's conversational AI understands English, Hindi, Hinglish, and Devanagari script. Buyers can speak or type naturally (*"Mujhe ₹3,000 ke andar wireless headphones chahiye"*) and get real recommendations from the actual catalog — not generic search results.

**For Trust** — Every agent action (search, recommendation, policy check, payment initiation) is gated through a 5-rule Policy Governance Engine and written to an immutable audit trail. The AI cannot place an order without passing all checks and logging every step.

## Key Features

### Seller Dashboard
- **AI Catalog Normalizer** — Single-click or batch normalize raw product descriptions into structured agent-ready JSON (normalized name, search terms, attributes, use cases)
- **Live Analytics** — Real-time revenue, order counts, average order value across configurable timeframes (7d / 30d / quarter)
- **Commerce Policy Editor** — Set max discount, max order value, quantity limits, and confirmation requirements per product
- **CSV Import** — Bulk upload products from spreadsheet, with batch AI normalization

### Buyer AI Workspace
- **Multilingual Chat** — English, Hindi, Hinglish, Devanagari script — detected and responded to in the buyer's own language
- **Voice Input (STT)** — Web Speech API integration; buyers tap the mic and speak naturally
- **Multi-turn Context** — Follow-up queries like *"sasta wala konsa hai"* or *"buy the first one"* resolve against the previous conversation without a vector database
- **Side-by-side Comparison** — Triggered by "compare", "vs", "fark" — generates a structured comparison matrix
- **Buyer Budget Ceiling** — Personal spend limit enforced by the agent independent of the seller's policy
- **Chat History** — Multiple sessions saved locally; switch between conversations

### Checkout & Governance
- **Razorpay Integration** — Orders created server-side via Razorpay API; payment modal opens natively inside the chat
- **5-Gate Policy Engine** — Stock check → Quantity limit → Discount cap → Order value ceiling → User confirmation gate
- **Immutable Audit Trail** — Every agent action logged with type, input, output, status, and reason
- **Failure Recovery** — Agent handles out-of-stock, price changes, and payment failures gracefully with explainable recovery messages

## Local Setup

### Prerequisites

- Node.js 20+
- npm or pnpm
- A Supabase project (free tier works)
- Groq API key (free at [console.groq.com](https://console.groq.com))
- Google Gemini API key (optional, used as fallback)
- Razorpay Test credentials (free at [dashboard.razorpay.com](https://dashboard.razorpay.com))

### 1. Clone & Install

```bash
git clone https://github.com/Vansh1535/Shopagent.git
cd Shopagent
npm install
```

### 2. Configure Environment

```bash
cp .env.example .env.local
```

Fill in `.env.local`:

```env
# Supabase
NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key

# AI (Groq is primary, Gemini is fallback)
GROQ_API_KEY=your_groq_api_key
GROQ_MODEL=llama-3.3-70b-versatile
AI_API_KEY=your_gemini_api_key

# Razorpay Test Mode
RAZORPAY_KEY_ID=rzp_test_...
RAZORPAY_KEY_SECRET=your_secret
NEXT_PUBLIC_RAZORPAY_KEY_ID=rzp_test_...
```

### 3. Set Up Database

Run `supabase/schema.sql` in your Supabase Dashboard → SQL Editor.

### 4. Seed Demo Data

Start the dev server, then hit:

```
GET http://localhost:3000/api/seed
```

### 5. Run

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## How the Agent Works

1. **User sends a message** (text or voice) in any language
2. **Intent is classified** — buy intent, comparison, follow-up, or new search
3. **Catalog search** — Groq LLaMA or Gemini searches the normalized product database semantically
4. **Policy check** — 5 gates validated before any checkout action
5. **Razorpay order created** server-side if all gates pass
6. **Payment modal opens** inside the chat thread
7. **Every step is logged** to the audit trail with full input/output context
